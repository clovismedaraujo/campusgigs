# CampusGigs

Marketplace de serviços entre universitários — conecta estudantes que precisam de pequenos serviços (aula particular, revisão de texto, ajuda com tarefas) a colegas que querem oferecê-los, dentro do próprio campus.

Projeto desenvolvido para a disciplina **DIM0510 — Processos de Software**.
